# Haunted Mansion Text Adventure Game

**Author:** Kingume49

## Description

Haunted Mansion is a Python text-based adventure game where players explore a mysterious mansion, collect six hidden items, and avoid the Ghost. The goal is to collect all six items before entering the Secret Room.

## Objective

* Explore the mansion by moving between rooms.
* Collect all six items.
* Avoid entering the Secret Room before collecting every item.
* Win by collecting all items before encountering the Ghost.

## Items to Collect

1. Ancient Book
2. Silver Key
3. Flashlight
4. Knife
5. Rope
6. Amulet

## Commands

* `go North` — Move north.
* `go South` — Move south.
* `go East` — Move east.
* `go West` — Move west.
* `get [item name]` — Collect an item in the current room.

## How to Run the Game

1. Install Python on your computer.
2. Open the project in PyCharm or another Python IDE.
3. Open `TextBasedGame.py`.
4. Run the program.
5. Follow the instructions and enter commands when prompted.

## Technologies Used

* Python
* Dictionaries
* Functions
* Loops
* Conditional statements
* User input and validation

## Win and Lose Conditions

**Win:** Collect all six items before entering the Secret Room.

**Lose:** Enter the Secret Room before collecting all six items.
